# 🎨 浏览器换肤插件

一个功能丰富的浏览器换肤插件，支持多主题、自定义背景、打字动效和拉灯绳交互。

## ✨ 功能特性

### 🎯 核心功能
- **8种预定义主题**：经典、复古、清醒、羊皮纸、深色、自然、海洋、日落
- **自定义图片背景**：支持联网搜索、透明度调节、毛玻璃蒙版、明暗度调整
- **打字动效系统**：粒子动效、水波纹动效、环绕光晕效果
- **拉灯绳交互**：下拉灯绳随机切换主题，伴随闪光动画
- **多浏览器兼容**：支持 Chrome、Edge、Firefox 等现代浏览器

### 🛠️ 技术特性
- 基于 Manifest V3 开发
- 使用现代 CSS3 动效
- 响应式设计，适配各种屏幕尺寸
- 性能优化，避免页面卡顿
